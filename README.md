### 🚀 About Me

- 🧠 **AI & Agent Architecture**: Designing autonomous agent systems, Model Context Protocol (MCP) integrations, and Spec-Driven Development (SDD) pipelines.
- ⚡ **Local LLM & Edge Inference**: Building high-performance local inference workflows using `llama.cpp`, Ollama, LM Studio, Whisper.cpp, and Piper TTS with CUDA/Vulkan hardware acceleration.
- 🏛️ **Software Engineering Foundations**: Applying Clean Architecture, Domain-Driven Design (DDD), containerization, and strict validation contracts across fullstack environments.
- 🛠️ **Developer Tooling**: Author of developer utilities, including the [NVIDIA NIM OpenCode Provider](https://github.com/NezerkC/opencode-provider-nvidia-nim) supporting 42+ state-of-the-art models.
